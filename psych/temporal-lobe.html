Temporal Lobe

Temporal Lobe

Location: Sides of brain, near temples (left and right)

Key Structures

Auditory Cortex

  • Location: Superior temporal lobe
  • Function: Processes sound frequencies
  • Processes: Pitch, volume, tone, speech sounds

Wernicke's Area (Language Comprehension)

Location: Left temporal lobe (superior temporal gyrus)

Function: Understanding spoken and written language

Memory Systems

  • Hippocampus: Long-term memory formation
  • Amygdala: Emotional memory
  • Stores: Autobiographical memories, facts, events

Language Processing

Wernicke's Area Role

  1. Receives: Auditory input from primary auditory cortex
  2. Processes: Meaning of words and sentences
  3. Connects: To Broca's area for language production
  4. Connects: To hippocampus for memory

What Happens with Damage

Ability Status
Understanding LOST
Speaking Fluent but nonsensical
Repetition Poor (doesn't understand)
Reading Often affected
Awareness May not realize speech is wrong

Other Functions

Emotional Processing

  • Recognizes emotional meaning of words/tones
  • Links sounds to emotional memories

Face Recognition

  • Inferior temporal regions
  • Recognizes familiar faces
  • Damage = prosopagnosia (can't recognize faces)

Music Processing

  • Right temporal lobe for melody
  • Left temporal for rhythm
  • Musical memory storage

Clinical Significance

Temporal Lobe Seizures

  • Most common type of focal seizure
  • May cause:
    • Auditory hallucinations
    • Déjà vu
    • Emotional changes
    • Memory disruption

Alzheimer's Disease

  • Temporal lobes (hippocampus) severely affected
  • Memory loss is primary symptom
  • Progressive language comprehension decline
