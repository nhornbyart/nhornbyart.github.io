Biofeedback

Biofeedback

Definition: Process of learning to control bodily states using specialized machines that provide real-time information about physiological changes

How Biofeedback Works

Measured Parameters

Historical Example: Budzyński (1973)

Study: Teaching muscle relaxation through biofeedback

Setup

  • Patients had tension headaches
  • Measured forehead muscle tension (EMG)
  • Provided visual feedback
  • Taught to relax these muscles

Results

  • Success: Significantly reduced tension headaches
  • Patients learned to control muscle tension
  • Effects lasted after treatment ended

Mechanism

  1. See forehead tension rising → stress response
  2. Try relaxation techniques
  3. See tension drop on display → positive reinforcement
  4. Learn mind-body connection
  5. Apply skill in daily life

Clinical Applications

Treatment Process

Phase Duration Focus
Assessment 1-2 sessions Baseline measurements, goals
Training 5-10 sessions Learn to recognize patterns, develop control
Practice Ongoing Transfer skills to real-world situations
Maintenance Long-term Continued skill application

Why It Works: The Mind-Body Connection

  1. Awareness: Real-time feedback shows the connection
  2. Control: Discover you can influence physiology
  3. Reinforcement: Success with techniques builds confidence
  4. Generalization: Learned control applies outside lab

Altered State Status

Is Biofeedback an Altered State of Consciousness?

Possible Arguments:

For:

  • State of focused, narrowed attention
  • Different brain wave patterns
  • Relaxation response distinct from normal waking

Against:

  • Person remains fully conscious
  • More like skill-learning than consciousness alteration
  • Not quite the same as meditation or hypnosis

Conclusion: Arguably yes—it produces sustained physiological changes distinct from normal waking consciousness
